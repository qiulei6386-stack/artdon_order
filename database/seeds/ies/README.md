# Preliminary demo IES fixtures

Every `.ies` file in this directory is synthetic photometry created only to
exercise the Lighting Simulation workflow.

- The files are not supplied by a manufacturer.
- The files are not based on laboratory measurements.
- The files are not approved for construction, procurement, compliance, or
  product-performance claims.
- Replace each demo profile with a verified optical variant before relying on
  the result for a real project.

The application exposes the same status and disclaimer in its product API,
simulation response, saved project, and PDF report.
